Context

Why this matters

The World Health Organization estimates that more than 1 billion people need at least one assistive product, but only 1 in 10 has access, because of high prices, lack of awareness and a shortage of trained staff.

WHO describes assistive technology as a part of health technology that helps people live healthy, independent and dignified lives, and says it can reduce the need for long-term care and the work of caregivers.

AccessAI is assistive software that runs on an ordinary laptop with pay-per-use cloud. No special hardware, so more people can reach it.

Sources:

— WHO, "WHO convenes global stakeholders to improve access to assistive technology" (2019)

— PAHO, "Global Report on Effective Access to Assistive Technology Consultation" (2021)

Process

How it works

Three effortless steps from thought to action — no technical knowledge needed.

01
🎙️
Speak

Say a natural command out loud — just like talking to a person. No special syntax or memorized phrases required.

02
🧠
Agent understands

Claude on Amazon Bedrock parses intent, selects the right tool, and plans the actions needed — all in under a second.

03
⚡
Action happens

The agent executes the command on your computer — opening apps, typing text, scrolling, adjusting settings, and more.

Capabilities

7 powerful tools

A complete toolkit for hands-free computer control — from the desktop to the browser and beyond.

🖥️
SystemControl
Desktop

Launch applications, manage windows, lock your screen, take screenshots, and control the OS itself — all by voice.

🌐
BrowserControl
Web

Navigate to URLs, click links, fill forms, switch tabs, and interact with any website using conversational commands.

📁
FileManager
Files

Open, move, rename, and search files and folders. Hands-free access to your entire file system.

⌨️
TextInput
Input

Dictate and insert text anywhere — documents, emails, search bars, chat apps — with AI-assisted formatting.

↕️
ScrollNavigation
Navigation

Scroll pages up, down, left, right — fast or slow. Navigate long documents and websites hands-free.

🔊
VolumeControl
Audio

Raise, lower, mute, or unmute system and app audio instantly. Keep full audio control without touching the keyboard.

👁️
ScreenReader
Accessibility

Ask the agent what's on screen. It uses vision AI to describe UI elements, read out content, and guide navigation.

Why it matters

Technology should work for everyone

🌍
A massive, underserved population

Over 1 billion people globally live with motor, mobility, or neurological disabilities that make mouse and keyboard use painful or impossible — yet most software still assumes able-bodied input.

🤝
Independence through AI

AccessAI Agent transforms the computer from an obstacle into an ally — giving users the freedom to work, communicate, and create without depending on others for basic tasks.

⚡
Natural language, zero friction

No custom scripts, no learning special commands. If you can say it, the agent can do it — meeting users where they are.

Infrastructure

Built with AWS

Enterprise-grade cloud infrastructure powering every voice command with reliability, security, and scale.

🤖
Amazon Bedrock
AI & Foundation Models

Claude Sonnet powers the agent's reasoning and intent parsing — understanding ambiguous voice commands and selecting the right actions in milliseconds.

🗄️
Amazon DynamoDB
NoSQL Database

Stores session history, user preferences, and command logs with single-digit millisecond latency — keeping the agent context-aware across sessions.

☁️
AWS Elastic Beanstalk
Application Hosting

Fully managed deployment and auto-scaling for the agent's backend — zero infrastructure overhead so the focus stays on accessibility.
